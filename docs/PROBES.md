# Evidence probes

Generated by `tools/gen_docs.py`. Do not edit by hand.

MacSIEM never runs the commands documented in the LOOBins corpus -- roughly 40 of them destroy evidence or disable security controls. It runs this catalog instead: 92 read-only probes (67 executed, 25 native in-process readers).

| policy_excluded | 0 | disabled by privacy configuration |

## Declared safety exceptions

Every probe that needs an exemption from a generic guard rule declares it here, with its justification. There are 6.

- **`identity.guest_account`** - `-guestAccount status` reads state; the mutating spellings are `on`/`off` and are rejected by the argument validator
- **`provenance.xattr`** - `-l` lists; the mutating spellings are -d/-c/-w and are rejected
- **`storage.spotlight_recent`** - `mdfind` takes a query expression containing `$time.now(-N)`; validated by the Spotlight-query validator, never a shell
- **`logs.unified_window`** - `log show --predicate` is the one argument that may contain quoting; it is checked by the predicate validator
- **`logs.unified_security`** - predicate argument, as above
- **`content.screenshot`** - writes exactly one file, and the path is forced to be inside the bundle directory by the artifact-slot validator
